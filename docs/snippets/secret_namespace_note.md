!!! note "Namespace must match Holmes' deployment"
    Create the secret in the same namespace where Holmes runs. The `-n holmes` flag in the **Holmes Helm** tab and `-n default` in the **Robusta Helm** tab match each chart's documented defaults — adjust if you installed Holmes/Robusta into a different namespace. If the secret is not in that namespace, the Holmes pod does not start: it stays in `CreateContainerConfigError` and its events show `Error: secret "<name>" not found`.
