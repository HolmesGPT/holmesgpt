!!! note "Namespace must match Holmes' deployment"
    Create the secret in the same namespace where Holmes runs. The `-n holmes` flag in the **Holmes Helm** tab and `-n default` in the **Robusta Helm** tab are examples: use the namespace you installed the chart into. The Holmes install guide passes no `-n`, so it installs Holmes into your kubectl context's namespace, `default` unless you set another. `helm list -A` shows each release's namespace. If the secret is not in that namespace, the Holmes pod does not start: it stays in `CreateContainerConfigError` and its events show `Error: secret "<name>" not found`.
